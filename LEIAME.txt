	SGJogos - Material da Avaliação da Etapa 1 (DSW 2026.2)
=======================================================

Este pacote contém:

  html/index.html       Página inicial: lista de equipes e modalidades
  html/equipe.html      Página de detalhes de uma equipe
  html/modalidade.html  Página de detalhes de uma modalidade
  css/style.css         Folha de estilos usada pelas três páginas
  .gitignore            Arquivo que deve ser colocado na raiz do seu repositório

Observações:

- Abra os arquivos .html no navegador para ver como cada página deve ficar.
- Os dados exibidos nas páginas são apenas exemplos. No seu sistema, tudo
  deve vir do banco de dados.
- Os comentários dentro dos arquivos .html mostram o que exibir quando não
  houver dados (por exemplo, uma equipe sem atletas).
- Não altere o style.css. Se precisar de outra regra de estilo, crie-a em
  outro arquivo.
- O arquivo .gitignore começa com ponto e pode ficar oculto no seu sistema.
  No Linux/Mac, use "ls -a" para vê-lo. No Windows, ative "Itens ocultos" no
  Explorador de Arquivos.
